THE SCIENCE

Four classifiers, published formulas, zero mystery

Every projection this platform surfaces traces back to a named statistical method with a closed-form equation — no gradient-boosted black box, no "trust the neural net." Each is implemented natively in Rust and covered by unit tests.

1. No-Vig Consensus Probability

mlb-core::analysis

Sportsbook odds embed a built-in margin ("vig") that inflates implied probabilities above 100%. We strip it independently from FanDuel and DraftKings, then average the two books' fair probabilities into a single consensus estimate of the true win probability for a given side.

Implied probability from American odds
p(price) = price ≥ 0 ? 100 / (price + 100) : |price| / (|price| + 100)
De-vig (normalize a two-way market to sum to 1)
fair(A) = p(A) / (p(A) + p(B))

A book's line is flagged +EV whenever its own posted price implies a probability below the cross-book consensus fair probability — the gap between the two is the edge.

2. OLS Trend Regression & Polarity Classifier

mlb-predict::trend

For a player's season-by-season rate statistic (K/9, HR/G, ERA, ...), we fit an ordinary least squares regression line across seasons and classify the slope into a three-state label. Crucially, "increasing" and "improving" are not the same thing — a rising ERA is bad, a rising K/9 is good — so the direction classifier is composed with a per-statistic polarity flag before it's ever shown to a user.

Ordinary least squares slope
β₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
Direction classifier (scaled to the stat's own magnitude)
direction = Increasing if β₁ > 0.03 · max(|ȳ|, 0.5) Decreasing if β₁ < −0.03 · max(|ȳ|, 0.5) Stable otherwise

3. Poisson Count Model for Player Props

mlb-predict::projection

Low-count discrete stats (strikeouts, hits, home runs) are well modeled by a Poisson distribution. We project a player's expected count (λ) as the mean of their last 10 cached games, then compute the exact model-implied probability the posted Over/Under line hits — giving every prop an edge estimate even when only one book quotes it.

Recent-form projection
λ = (1/n) · Σ statᵢ, over last n ≤ 10 games
P(Over) under Poisson(λ) for half-integer line k+0.5
P(X > k) = 1 − e⁻λ · Σ (λⁱ / i!), for i = 0 … k

A safeguard flags high-divergence picks where model and market disagree by more than 30 percentage points or 50% EV — these are surfaced with an explicit "verify lineup" caution rather than presented as confident edges, since large gaps usually signal a role change or lineup uncertainty rather than true mispricing.

4. Pythagorean Win Expectation + Log5

mlb-predict::game_model

Pre-game win probability is estimated with two well-established sabermetric formulas — not a black-box ML model. "Pythagenpat" estimates each team's true winning percentage from season runs scored/allowed (more stable than raw win-loss record), and Bill James' Log5 method combines both teams' win percentages into a single head-to-head probability, plus a small home-field nudge.

Pythagenpat win expectation (exponent 1.83)
win% = RSᵉ / (RSᵉ + RAᵉ), e = 1.83
Log5 (Bill James)
P(A beats B) = (pₐ − pₐpᵦ) / (pₐ + pᵦ − 2pₐpᵦ)

The resulting probability is compared directly against the market's de-vigged moneyline price to surface a model-vs-market edge, in percentage points.

FROM MODEL TO DASHBOARD

Where each classifier shows up

The four models above aren't academic exercises — each one powers a specific, live dashboard surface backed by real FanDuel and DraftKings lines.

📈

Best Expected Value

De-vigs FanDuel and DraftKings independently, averages their fair probabilities, and ranks every line by true +EV — plus a second edge source driven by player-prop model projections.

⚖️

Arbitrage Detection

Continuously scans both books for guaranteed-profit mismatches across moneylines, spreads, and totals.

🎯

Player Prop Projections

A recent-form Poisson count model projects each player's expected stat line from their last 10 cached games, surfacing edges even when only one book quotes a prop.

🧮

Win Probability Model

Pythagorean win expectation combined via the Log5 method (plus home-field adjustment) estimates true moneyline win probability vs. the market's de-vigged price.

📊

Trend & Matchup History

Free MLB Stats API data, cached in SQLite, powers season-over-season trend regression and last-N-meetings-vs-opponent breakdowns.

🤖

Parlay Assistant

An Anthropic Claude-powered chat tab builds parlays strictly from real data in the database — it's instructed to never invent odds, players, or lines.
